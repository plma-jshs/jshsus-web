# 관리자 날짜 표시 규칙

관리자 화면의 날짜·일시 표시에는 `apps/admin/src/shared/lib/date.ts`의
`formatAdminDate`를 사용한다.

- 한국 시간(`Asia/Seoul`) 기준으로 올해 데이터는 연도를 생략한다. 예: `08.16`, `08.16 14:30`
- 올해가 아닌 데이터는 연도를 포함한다. 예: `2025.08.16`, `2025.08.16 14:30`
- 날짜 구분자는 하이픈(`-`)이 아니라 점(`.`)을 사용한다.
- 날짜 입력값, API payload, 엑셀/파일 export 값은 이 규칙을 적용하지 않고 기존 기계 판독용 형식을 유지한다.

이 규칙은 표시용 helper를 통해 강제한다. 단순한 ESLint 규칙만으로는 날짜 표시와
입력·전송·계산 코드를 안정적으로 구분하기 어렵기 때문에, 새 관리자 날짜 표시를
추가할 때 helper를 직접 사용하고 코드 리뷰에서 확인한다.
