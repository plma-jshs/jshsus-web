# 계정 활성화와 비밀번호 재설정

## 학생 계정 배부

1. 관리자가 새 학년도 학생 명단을 등록하면 학번은 명단의 학번을 그대로 사용한다.
2. 관리자 학생 관리 화면에서 `인증코드 일괄 발급`을 실행하고 CSV를 다운로드한다.
3. 각 학생에게 학번과 해당 학번에 매칭된 1회용 인증코드를 개별 배부한다.
4. 학생은 `통합로그인 계정 만들기`에서 학번과 인증코드, 이름, 성별, 이메일, 휴대폰 번호, 새 비밀번호를 입력한다.

학생이 임의의 학번을 새로 발급받는 구조가 아니다. 학번은 새 학기 명단에서 확정되고, 인증코드만 서버가 개별 생성한다.

## 교직원 계정 배부

1. 관리자가 교직원을 생성하면 `identity_sequences`를 사용해 중복되지 않는 6자리 교사번호를 서버가 자동 할당한다.
2. 생성 직후 해당 교사번호의 1회용 인증코드를 발급해 관리자에게 한 번만 표시한다.
3. 관리자는 교직원에게 교사번호와 인증코드를 배부한다. 자동 발급이 실패하면 해당 행의 `더보기`에서 인증코드를 다시 발급한다.

## 이메일 비밀번호 재설정

사용자는 이메일 주소를 다시 입력하지 않고, 계정에 이미 연결되고 Cognito에서 검증된 이메일을 사용한다.

1. API는 학번 또는 교사번호를 조회하고, 비활성·미연결·이메일 미검증 계정을 배제한다.
2. 조건을 만족하면 Cognito `ForgotPassword`가 검증된 이메일로 코드를 전송한다.
3. API는 재설정 흐름을 Redis에 제한 시간 동안만 보관하며, 사용자가 코드와 새 비밀번호를 제출하면 Cognito `ConfirmForgotPassword`로 확정한다.
4. 성공하면 재설정 흐름을 삭제하고 기존 로그인 세션을 모두 무효화하며 감사 로그를 남긴다.

계정 존재 여부를 추측하지 못하게 미존재·비활성·이메일 미검증 계정도 요청 단계에서는 동일한 성공 응답을 반환한다. 휴대폰 방식은 Cognito가 아닌 Sendon 알림톡·SMS로 서버가 생성한 6자리 코드를 보내는 별도 흐름을 사용한다.
