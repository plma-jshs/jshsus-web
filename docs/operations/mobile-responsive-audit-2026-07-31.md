# 모바일 반응형 점검

점검일: 2026-07-31

## 점검 방법

- 공개·관리자 기능별 CSS가 모바일 분기점을 갖는지 정적 점검했다.
- 고정 폭 그리드, 가로 테이블, 모달, 달력, 에디터와 미디어 임베드를 우선 확인했다.
- 공통 `responsive.css`와 각 기능 CSS의 `@media` 규칙이 실제 컴포넌트 클래스에
  연결되는지 확인했다.

## 결과

모바일 분기 자체가 전혀 없는 기능별 CSS 파일은 발견되지 않았다. `base.css`,
`global.css`, `home.css`는 기능별 분기가 없는 파일로 잡히지만, 홈과 공통 셸의 실제
모바일 전환은 `responsive.css`에서 처리한다.

이번 변경으로 다음 두 화면을 추가 보완했다.

- 탐구활동서: 7개 열을 모바일 카드형 행으로 전환하고 각 값에 라벨을 붙였다.
  기간 필터는 한 열로 쌓이며 활동 인원은 데스크톱에서 최대 두 줄까지 표시한다.
- 기상곡 신청: 데스크톱에서는 영상/신청 제어 2단, 900px 이하에서는 1단으로
  전환한다. 신청 내역 표는 기존 가로 스크롤을 유지한다.

관리자 화면의 데이터 테이블은 공통 `DataTable` 스크롤 컨테이너를 사용하고, 각
기능의 입력 그리드는 760~900px 구간에서 한 열 또는 두 열로 줄어든다. 학사일정
관리 달력은 760px 최소 폭의 가로 스크롤을 의도적으로 사용하므로 작은 화면에서
잘리는 대신 스크롤로 접근 가능하다.

## 후속 회귀 점검 기준

배포 전후 다음 뷰포트에서 가로 문서 스크롤, 잘린 버튼, 겹친 모달이 없어야 한다.

- 390 × 844: 공개 탐구활동서, 기상곡 신청, 에디터 모달
- 768 × 1024: 공개/관리자 달력, 상벌점, 사용자 관리
- 1280 × 800: 넓어진 탐구활동서 표와 기상곡 2단 레이아웃

새 페이지는 기능 CSS에 모바일 분기 또는 공통 반응형 컴포넌트 사용 여부를 코드
리뷰 체크리스트로 남긴다.
